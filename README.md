# Demian Tarasov · `@krisikas`

### Sofware Architect & Robotics Engineer

I focus on software architecture, backend systems, and autonomous robotics — building modular services, telemetry pipelines, and control software for UAVs and embedded devices.

---

### Core Competencies

- **Backend & System Architecture**: Designing modular, decoupled services in Python (FastAPI) and Go. Building REST and WebSocket APIs for live telemetry streaming, state persistence with PostgreSQL, and multi-container orchestration.
- **Autonomous Systems & UAVs**: Developing C++ ROS 2 nodes, finite-state offboard flight controllers, safety monitors, and trajectory trackers. Building reproducible SITL simulation environments (PX4, Gazebo Harmonic) on macOS/Linux.
- **Hardware & AI Tooling Integration:** Writing embedded C/C++ firmware for STM32 and ESP32, designing schematics and PCBs in KiCad, and implementing MCP (Model Context Protocol) servers to expose control and telemetry interfaces to LLMs.
