# Demian Tarasov · `@krisikas`

### Systems Architect & Robotics Engineer

I build high-performance distributed backends, autonomous UAV pipelines, and hardware-integrated systems that bridge software with the physical world.

---

### Core Competencies

- **Backend & System Architecture**: Designing robust microservice ecosystems, high-throughput asynchronous pipelines, and low-latency network protocols (WebSockets, gRPC, TCP, REST).
- **Autonomous Systems & UAVs**: Full-stack drone engineering — flight dynamics, PX4 Autopilot (SITL), Gazebo Harmonic simulation, and ROS 2 middleware for GPS-denied environments.
- **AI & Agentic Infrastructure**: Orchestrating LLM/VLM reasoning agents with physical actuators and telemetry streams using the Model Context Protocol (MCP) and deterministic tool calling.
- **Hardware & Embedded Engineering**: Circuit schematic design, mechanical CAD modeling, and real-time C++ firmware development for embedded platforms.
